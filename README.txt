AMS BARBERSHOP - VERSI LENGKAP
================================

1. Copy folder ini ke:
   C:\xampp\htdocs\ams_barbershop

2. Jalankan Apache dan MySQL di XAMPP.

3. Buka:
   http://localhost/phpmyadmin

4. Buat database bernama:
   database

5. Import:
   database.sql

6. Buka website:
   http://localhost/ams_barbershop/

7. Login admin:
   http://localhost/ams_barbershop/login.php

   Username: admin
   Password: admin123

Catatan:
- config.php sudah memakai database bernama "database".
- Jika MySQL root memakai password, ubah $DB_PASS di config.php.
- Jangan membuka file PHP dengan double click. Jalankan melalui localhost.
